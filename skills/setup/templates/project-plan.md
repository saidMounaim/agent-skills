# Project plan

> You own this file. Fill it yourself or run `discover`. Leave a line blank rather than guess.

## 1. Problem
What problem does this solve? One or two sentences.

## 2. Users
Who uses it? Main user types and what each needs.

## 3. Features (first version)
One line per feature. The ordered, numbered list goes in build-plan.md.

## 4. Data
What is stored? Main entities and how they relate. Anything that must never change once written?

## 5. Tech
Language, framework, database, auth, hosting, third-party services (email, payments, files, AI).

## 6. Money
How does it make money, if at all? Does the product itself handle prices, taxes or currencies?

## 7. UI / UX
Look and feel. Screens and mockups go in `plan/references/`. Design rules go in `design.md` (run `design`).

## 8. Deployment
Host, build and start commands, env variable NAMES (never values), database, background jobs, health check, domain.

## 9. Constraints (optional)
Expected scale, public or internal, single or multi-tenant, compliance (tax, privacy), languages, explicit non-goals.
