# Workflow init

Sets up file-backed state so plans, the active spec, findings and history live in the repo, not in chat memory. Any agent (Claude Code, Codex) can pick up the work from these files.

## Preconditions

- The app is already scaffolded (Next.js, NestJS, whatever). This workflow sits on top of an app; it does not create one.
- It is a git repository with a clean working tree. If not, stop and tell the user.
- `plan/build-plan.md` does not exist yet. If it does, stop: the workflow is already installed (suggest `build-status`).

## Steps

1. Create this tree from the files in this skill's `templates/` folder:

```
plan/
  project-plan.md        # user-owned: product, users, data, stack, deploy
  build-plan.md          # user-owned: ordered feature checklist with stable IDs
  context/
    overview.md          # generated by project-discovery from both plans
    current.md           # the ONE active feature/fix spec (empty stub)
    findings.md          # review findings ledger (empty stub)
    review.md            # latest cross-review request + receipt (empty stub)
  history/
    features/            # archived specs, written by complete-feature
    fixes/
```

2. Detect the project's commands from package.json / Makefile / pyproject: typecheck, lint, test, build, e2e. Combine them into ONE `Verify` command (e.g. `pnpm typecheck && pnpm lint && pnpm test && pnpm build`). Ask the user to confirm it.
3. Append the block from `templates/agents-block.md` to `AGENTS.md` (create it if missing) with the Verify command filled in. If `CLAUDE.md` exists, add one line to it: `Follow the Workflow section in AGENTS.md.` If it does not exist, create it with that line.
4. Show the user the created files and say what comes next:
   - fill `plan/project-plan.md` and `plan/build-plan.md` themselves, or
   - run `project-discovery` to fill them through an interview.
5. Offer a commit: `chore: add spec-driven workflow`. Commit only after the user says yes.

## Gotchas

- Do not overwrite an existing AGENTS.md or CLAUDE.md. Append, and show the diff.
- If the project has no tests yet, say so. Note in AGENTS.md: "No test runner yet. First build-plan item should add one."
- Scaffolding and visual prototypes are not build-plan features. They happen before item 1.
